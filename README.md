# Macy Hanzlik — Journalism Portfolio

A responsive, static portfolio website designed for GitHub Pages.

## Files
- `index.html` — homepage
- `work.html` — selected published work
- `audio.html` — audio journalism
- `about.html` — biography and skills
- `styles.css` — visual design
- `script.js` — mobile navigation and footer year
- `assets/` — images

## Before publishing
1. Replace `YOUR-EMAIL@example.com` in all HTML files with your professional email.
2. Replace sample headlines, dates, descriptions and `href="#"` links on `work.html` and `audio.html` with real clips.
3. Review the About page carefully and adjust any wording that doesn't sound like you.
4. Keep or replace `assets/portrait-placeholder.svg`. If you don't want a portrait, replace it with a relevant photo you have rights to use.
5. Search all files for `[`, `YOUR-`, and `href="#"` to find remaining placeholders.

## Publish with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new **public** repository named exactly `YOUR-USERNAME.github.io`.
3. Upload the contents of this folder (not the enclosing folder) to the repository's root.
4. In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Your site will appear at `https://YOUR-USERNAME.github.io` after GitHub finishes publishing.

You can add a custom domain later. A domain name costs money annually; GitHub Pages hosting for a public repository is free.

## Editing later
Open the relevant `.html` file in GitHub and edit the text or links, or edit locally and upload the updated files. Keep filenames and relative links unchanged.
